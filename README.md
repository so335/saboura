# 🎓 سبورة المعرفة التفاعلية

تطبيق متكامل لإدارة الحصص الدراسية مع استطلاعات مباشرة، تذاكر خروج رقمية، وبث مباشر للطالبات.

## 📁 هيكل المشروع

```
.
├── index.html    ← الصفحة الرئيسية (170 كيلوبايت)
├── style.css     ← التنسيقات (347 كيلوبايت)
└── script.js     ← البرمجة (949 كيلوبايت)
```

## 🚀 طريقة الاستخدام

### 1. فتح محلياً
افتح ملف `index.html` في أي متصفح حديث.

### 2. رفع على GitHub Pages
1. أنشئ مستودع جديد على GitHub
2. ارفع الملفات الثلاثة
3. اذهب إلى Settings → Pages
4. اختر الفرع الرئيسي (main)
5. انتظر دقيقة ثم افتح الرابط

## ⚡ لماذا تم تقسيم الملف؟

الملف الأصلي كان ضخماً جداً (1.42 ميجابايت في ملف واحد) مما يجعله:
- بطيئاً في الفتح
- صعباً في التعديل
- ثقيلاً على المتصفح

بعد التقسيم:
- يُحمل HTML أولاً بسرعة
- CSS وJS يُحملان بشكل متوازٍ
- المتصفح يخزن CSS وJS مؤقتاً (cache)
- أسهل في التعديل والصيانة
